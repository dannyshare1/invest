# CORE — 核心投资规则

1. 估值优先
   不因股价跌得多就认为便宜，也不因现金多就强行买入。
   买入必须建立在基本面仍成立且估值有足够安全边际之上。

2. 估值必须动态更新
   财报、盈利预测或基本面变化后，必须用最新数据重新计算估值，不能沿用旧的 forward PE、目标价或买入区间。

3. 组合优先于单股
   任何买入、卖出或期权操作，都要同时考虑组合集中度、现金占用和风险暴露。

4. 不做机械交易
   不因为固定涨跌幅、固定盈利比例或短期技术信号机械买卖。
   长期核心仓不因小幅上涨频繁止盈。

5. 技术面只决定时机
   基本面和估值决定“值不值得买”，技术面主要帮助决定“什么时候买”。

6. 少做动作
   没有明确优势时可以不交易。
   真正的买卖建议必须给出价格、估值或事件触发条件，而不是泛泛地说“逢低买”。
