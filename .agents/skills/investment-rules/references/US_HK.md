# US_HK — 美股、港股与期权规则

## 1. 账户与组合

- 每次分析已连接的 IBKR / Schwab 等账户时，重新识别新增、减仓和已清仓标的，不沿用旧名单。
- 现金、SGOV、BOXX、IB01/1B01（可能显示为 ISHUF）等按现金/现金等价物管理。
- 目标现金比例约 20%-30%。
- 所有新仓、加仓和期权卖方交易都要检查交易后现金与集中度。

## 2. 美股/港股个股估值

对主要持仓与重点候选，在数据可靠时优先检查：

- 最新价格
- TTM PE / PB（适用时）
- 最新机构一致预期 EPS / 净利润
- 相对上次一致预期的上调/下调
- 用最新价格自行重算 forward PE
- FCF yield、EV/EBITDA、PEG 或更适合的指标
- 3年/5年历史估值分位（可靠可得时）

财报发布后必须使用财报后的最新盈利预测重新估值，不能沿用财报前的 forward PE。

## 3. Sell Put

- 只卖真正愿意接货的 Put。
- 不能只因为权利金高、IV高、Delta看起来合适就卖。
- 必须评估有效接货成本、基本面、估值、集中度和现金压力。
- 不因为账面盈利达到 50%、70% 或其他固定比例就机械平仓。

优先提前平仓或展期的情况包括：

- 标的基本面明显恶化
- 不再愿意按有效接货成本持有
- 多张 Put 同时被指派会造成过度集中或流动性压力
- 现金压力测试后低于目标底线
- 账户资金或保证金风险
- 重大公司行动、重大事件或提前指派风险
- 剩余权利金相对手续费、价差、资金占用和替代机会已经很小

建议提前退出时，必须说明具体触发了哪一项。

## 4. Put 现金压力测试

评估任何现有或新增 Put 时，假设所有未到期且可能被指派的 Put 同时按执行价被指派：

1. 计算所需接货资金。
2. 必要时按可靠汇率折算。
3. 从现金/现金等价物中扣除。
4. 计算指派后的预计现金金额与现金比例。

指派后现金约 20%-30% 为理想；低于 20% 时原则上不新增 Put，并优先考虑降低资金压力。

## 5. Wheel 与 Covered Call

- Put 被指派后，不机械进入 Wheel 卖 Call。
- 先重新评估基本面、估值和退出意愿。
- 如果仍低估且愿意长期持有，可以暂不卖 Call。
- 接近合理价值且愿意在某价格卖出时，再考虑 Covered Call。
- 基本面恶化时直接处理股票，不靠不断卖 Call 等回本。

对已有 Covered Call，需要明确：

- 继续持有
- 平仓
- 展期
- 接受指派
- 锁定利润

以及各自触发条件。

## 6. 期权输出纪律

期权单独列出，不混在普通个股点评中。

每个 Put 尽量列出：

- 执行价
- 到期日
- 合约乘数
- 有效接货成本
- 潜在接货资金
- 若同时指派后的组合占比与现金影响

对 100 股以上且适合卖 Call 的持仓，可以明确给“要不要 Call”的判断，但必须基于估值和退出意愿，而不是机械收租。
