# 投资规则 Skill

## 1. 分析前读取

始终读取对应市场规则：

- A股：`references/A_SHARE.md`
- 美股、港股、期权：`references/US_HK.md`

涉及具体标的、组合、仓位或期权决策时，同时读取当前使用者可用的 `STATE.md`。

若 `STATE.md` 不存在或没有对应标的，则按无历史状态运行，不自行猜测。

## 2. 通用投资原则

### 1. 基本面和估值决定是否买，技术面决定什么时候买

不因股价跌得多就认为便宜，也不因现金多而强行买入。

分析必须使用当前可核实的基本面、财务数据、盈利预期和估值。

财报、指引、盈利预测或核心逻辑变化后，原有估值和买入区间必须重新评估。

技术面主要用于寻找更好的建仓、加仓或减仓位置，不单独构成长期投资理由。

### 2. 先确定目标仓位，再决定怎么买

任何新增仓位前，都应先判断该标的在组合中允许达到的目标或最大仓位。

价格下跌本身不能成为无限加仓的理由。

目标仓位主要由以下因素决定：

- 基本面确定性
- 估值安全边际
- 波动和下行风险
- 与现有持仓的相关性
- 整体组合风险和现金占用

达到目标仓位后，除非投资逻辑或组合结构发生新的变化，否则不因继续下跌机械加仓。

### 3. 分批建仓，不一次押满

对于需要建立较大仓位的标的，应优先设计分批建仓方案。

交易计划至少应明确：

- 当前仓位
- 目标仓位
- 首次建仓或下一档加仓条件
- 剩余可加仓空间
- 减仓或退出条件
- 投资逻辑失效条件

各档价格应根据估值、安全边际和市场结构决定，不使用固定跌幅机械划分。

### 4. 组合优先于单一标的

单个标的即使具有吸引力，也不能脱离整个组合判断。

新增股票或期权仓位时，应同时考虑：

- 单一标的集中度
- 行业和因子集中度
- 现金占用
- 潜在期权指派
- 极端情况下的组合承受能力

### 5. 没有优势就不交易

不因固定涨跌幅、固定盈利比例或短期技术信号机械买卖。

长期核心仓不因正常波动频繁止盈。

当估值、赔率或风险收益没有明显优势时，可以保持现金并等待。

## 3. 状态与规则更新

`STATE.md` 用于记录具体标的的当前状态、仓位、估值、触发条件和失效条件；它不是永久投资规则。

只有在使用者明确确认某条原则为长期正式规则时，才更新 `A_SHARE.md`、`US_HK.md` 或本 Skill 的通用原则。不得把临时个股观点自动升级成正式规则。
