# 投资规则 Skill

## 1. 分析前读取

始终读取对应市场规则：

- A股：`references/A_SHARE.md`
- 美股/港股/期权：`references/US_HK.md`

涉及具体标的、组合或期权决策时，同时读取当前使用者可用的 `STATE.md`。若不存在，则按无历史状态运行，不自行猜测。

## 2. 通用投资原则

1. 基本面与估值优先
   不因股价跌得多就认为便宜，也不因现金多就强行买入。买入必须建立在基本面仍成立且估值有足够安全边际之上。

2. 动态重估
   使用当前可核实的行情、财务和盈利预期。财报、指引、盈利预测或基本面变化后，必须重新估值，不沿用旧的 forward PE、目标价或买入区间。

3. 组合优先于单股
   买入、卖出和期权操作都要同时考虑组合集中度、现金占用和风险暴露。

4. 不做机械交易
   不因固定涨跌幅、固定盈利比例或短期技术信号机械买卖；长期核心仓不因小幅上涨频繁止盈。

5. 技术面只用于择时
   基本面和估值决定是否值得买，技术面主要帮助决定什么时候买。

6. 所有实际交易建议必须有计划
   明确催化或核心逻辑、买入/加仓条件、止盈、止损和时间止损，并给出价格、估值或事件触发条件及合适的仓位建议。

7. 少做动作
   没有明确优势时可以不交易；如果没有值得做的动作，就明确说明。

## 3. 状态与规则更新

`STATE.md` 用于记录具体标的的当前状态、触发条件、下一步动作和失效条件；它不是永久投资规则。

只有在使用者明确确认某条原则为长期正式规则时，才更新 `A_SHARE.md`、`US_HK.md` 或本 Skill 的通用原则。不得把临时个股观点自动升级成正式规则。
